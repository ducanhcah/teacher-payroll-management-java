# Quản lý lương giáo viên

Ứng dụng Java Swing quản lý thông tin và lương cán bộ, giáo viên.

## Chức năng

- Thêm, sửa, xóa và tìm kiếm hồ sơ giáo viên.
- Tính lương thực lĩnh từ lương cứng, thưởng và tiền phạt.
- Sắp xếp danh sách và đọc, lưu dữ liệu từ tệp.

## Công nghệ

- Java
- Java Swing
- Apache NetBeans

## Cách mở

Mở thư mục bằng Apache NetBeans, sau đó build và chạy dự án.
